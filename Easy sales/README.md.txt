# EasySales — Python Sales Calculator

EasySales is a simple sales calculator built with Python.

## Features
- Calculate product prices
- Calculate total sales
- Validate user input
- Generate a sales report

## Requirements
- Python 3

## How to run
1. Download `easysales.py`
2. Open a terminal in the project folder
3. Run:

```bash
python easysales.py
```
